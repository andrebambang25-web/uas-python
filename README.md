# 📌 E-Sport Management System (Python & SQLite)

## 📖 Deskripsi Proyek
E-Sport Management System adalah aplikasi berbasis **Python (CLI)** yang digunakan untuk mengelola data **Team, Player, dan Tournament** pada bidang e-sport.  
Aplikasi ini menerapkan konsep **OOP (Object Oriented Programming)**, **Database SQLite**, **Module & Package**, serta **percabangan dan perulangan**.

Proyek ini dibuat sebagai **tugas pemrograman** dan dijalankan melalui terminal / command prompt.

## 🧱 Konsep OOP
Aplikasi ini menggunakan class:
- `Team` → menyimpan data nama dan region team
- `Player` → menyimpan data nickname dan role player
- `Tournament` → menyimpan data nama dan prize pool

Setiap class berada pada folder `models`.
